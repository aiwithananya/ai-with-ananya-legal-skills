# House Format and Letterhead

Loaded at Step 3 only when the user supplies a letterhead or a previous notice.

---

## What to extract

**From a letterhead** (`.docx`, `.pdf`, or image):
- Firm or chamber name, as printed
- Address block, telephone, email, website
- Advocate name and enrolment number, if pre-printed
- Logo or emblem, and where it sits
- How much vertical space the letterhead occupies, so the body starts below it
- Any pre-printed footer, and the space it needs

**From a previous notice** — more useful than a letterhead alone, because it carries
the house voice as well as the house look:
- Reference number format, e.g. `AS/NI/2026/041`
- Date format and placement
- How the modes of dispatch are listed
- The opening formulation — the house version of "Under instructions from and on
  behalf of my client"
- Paragraph numbering style — `1.` or `(1)` or `1)`, and whether each paragraph
  opens with "That"
- How quotations from documents are set — indented, italicised, in quotation marks
- The demand formulation — the house version of "I, therefore, call upon you"
- The consequence, costs, reservation and record formulations
- Signature block layout and what appears under the name
- Font, point size, line spacing, alignment, margins

## Confirm before drafting

State what was extracted, in a short list, and ask the user to confirm. Do not
silently adopt a format — an old notice may contain formulations the user has since
abandoned.

## Conflict rules

**Form:** the uploaded house format wins over
`references/drafting-conventions.md`. Every time.

**Substance:** it does not. A prior notice that omits a mandatory recital, misstates
a compliance period, cites a repealed provision, or carries annexures does not
license repeating any of that. Where the uploaded document conflicts with a
statutory profile, follow the profile and tell the user what was changed and why.

**Anything the uploaded document is silent on** falls back to
`references/drafting-conventions.md`.

## Reproducing the letterhead

Where the letterhead is an image or a PDF, do not attempt to redraw it. Reserve the
space it occupies and place `[FIRM LETTERHEAD]` in the reserved block, so the
advocate can print onto letterhead stock or paste the block in. Say in the delivery
message that this is what was done.

Where the letterhead is a `.docx`, its header can be carried across directly.

## Do not

- Reconstruct a letterhead from memory of an earlier conversation. Ask each run.
- Assume the format from a previous run in this same conversation still applies to a
  different notice type without confirming.
- Adopt a formatting choice because it appeared once in the uploaded document. If a
  convention is not consistent across the document, ask which is current.
