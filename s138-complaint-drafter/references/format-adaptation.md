# Format Adaptation: Matching the User's Court and Sample

## If the user uploads a sample complaint
Read it fully before drafting. Extract and list back to the user:
- Cause-title wording and layout (court name, case number line, parties block)
- Heading style (caps, bold, underlined, centred)
- Paragraph numbering style and whether paragraphs open with "That"
- Opening formula ("MOST RESPECTFULLY SHOWETH" or other)
- How annexures are cited (for example "Annexure C-1", "Mark A", "Exhibit P-1")
- Prayer, verification and signature block layout
- Font, size, line spacing, margins if visible
Ask the user to confirm the list, then mirror it.

**Form follows the sample. Substance does not.** If the sample omits a required averment (for example the S.142(2) jurisdiction paragraph, the S.141 role of each director, or the timeline facts), cites a repealed provision (Cr.P.C. instead of BNSS), or uses a wrong section in a heading, follow `references/statutory-framework.md` and tell the user what you changed and why.

## If the user pastes court rules or a format
Apply them exactly. Anything they do not cover falls back to `assets/filing-set-template.md`.

## If there is no sample
Use `assets/filing-set-template.md` with the defaults in `references/firm-context.md`. If firm context is blank, use: A4, Times New Roman 12 pt, 1.5 line spacing, justified, 1 inch margins, page numbers bottom centre.

## Ask about the user's own samples for next time
At the end, ask: "Want me to remember this format? Paste these preferences into references/firm-context.md and re-upload the skill." Give them the exact lines to paste.
