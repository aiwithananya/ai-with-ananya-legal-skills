# Formatting QC Checklist

- [ ] Original wording unchanged (spot-check 5 random clauses against the input)
- [ ] One multi-level list drives all numbering; no hand-typed numbers
- [ ] No skipped or duplicated numbers after renumbering
- [ ] Every "Clause X" / "paragraph X" reference points to the right place (REF fields)
- [ ] Every defined term is defined once, before or at first use, and capitalised consistently
- [ ] Undefined capitalised terms and dead cross-references listed in the change log, not invented
- [ ] Headings use built-in Heading styles; TOC field present if requested
- [ ] Schedules and annexures each start on a new page with consistent headings
- [ ] Signature / execution block complete for every party
- [ ] Page numbering "Page X of Y" (or court style) works on every page
- [ ] Format matches the uploaded sample, or the chosen profile, item by item
- [ ] Change log at the top carries "[REQUIRES ADVOCATE REVIEW BEFORE EXECUTION / FILING]"
